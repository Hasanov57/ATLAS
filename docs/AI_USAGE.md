# ATLAS layihəsində AI istifadəsi bəyannaməsi

Layihənin tələbləri, dizayn nümunələri və demo üçün qəbul edilən qərarlar komanda tərəfindən təqdim olunub. Bu iş sessiyasında **OpenAI ChatGPT daxilində Codex** kod yazmaq və dəyişmək, xətaları tapmaq, testləri işlətmək, UI və loqo resurslarını hazırlamaq, README və texniki sənədləri yeniləmək üçün istifadə edilib. AI köməyi yalnız bug yoxlaması və loqo düzəlişi ilə məhdudlaşmayıb.

İstifadənin görünən nümunələri:

- Mövcud FastAPI/SQLite və React tətbiqinin sərnişin, operator, GPS, ETA, sıxlıq və xəbərdarlıq iş axınlarını yoxlamaq və təkmilləşdirmək.
- İstifadəçinin göndərdiyi dizayn şəkillərinə əsasən panel, xəritə, giriş və bildiriş ekranlarını dəyişmək.
- Səhifənin ağ qalması problemini brauzer testi ilə tapmaq, yol nişanları və dayanacaq qatını yoxlamaq, backend testlərini və frontend build-i işlətmək.
- İstifadəçinin təqdim etdiyi ATLAS loqo və ikonlarını tətbiqə uyğunlaşdırmaq.
- İstifadəçi göstərişləri əsasında README, arxitektura və təhvil sənədlərini hazırlamaq.

Bunlar söhbətdəki tapşırıqların **məzmun xülasəsidir**. Yazışmada verilmiş promptlardan qısa nümunələr: “brauzerde ag ekran gosterir onu duzelt”, “bildirislerde bunu swipe up le islemir onu duzelt smooth olsun”, “son defe yoxlanis et”. Bu nümunələr tam prompt arxivi deyil. Bu sessiyada təsdiqlənən AI aləti ChatGPT/Codex-dir; başqa alət istifadəsinə dair sübut yoxdur.

Tətbiqin işlək sıxlıq, ETA və xəbərdarlıq mexanizmləri qayda əsaslı alqoritmlərdir. Layihədə öyrədilmiş maşın öyrənməsi modeli və real dövlət identifikasiya inteqrasiyası yoxdur. Demo giriş seçimləri real şəxsiyyət təsdiqi aparmır. Komanda təqdimatdan əvvəl kodu, nümayiş axınını və bu bəyannaməni yoxlamalıdır.
