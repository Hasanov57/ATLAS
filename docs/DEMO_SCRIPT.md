# İki dəqiqəlik təqdimat ssenarisi

**0:00–0:20** — “BakuTransit AI sərnişin və operatoru eyni məlumat bazasında birləşdirir. Buradakı marşrutlar və GPS mövqeləri rəsmi deyil, nümayiş üçün simulyasiyadır.”

**0:20–0:50** — Sərnişin ekranında D1 marşrutunu və dayanacağı seçin. Xəritədə hərəkət edən avtobusları və marşrut məsafəsinə əsaslanan təxmini çatma vaxtını göstərin.

**0:50–1:10** — “Sərnişin sıxlığı anonim bildirir.” Yüksək sıxlığı seçib **Bildirişi göndər** düyməsini basın. Server təsdiqini göstərin.

**1:10–1:30** — Operator panelinə keçin. Yeni bildirişin lentdə, göstəricilərin isə API məlumatları əsasında göründüyünü göstərin. Bir nəfərin bildirişi təkbaşına xəbərdarlıq yaratmır.

**1:30–1:50** — **Yüksək sıxlıq ssenarisini başlat** düyməsinə basın. Təqdimat avtomatik olaraq tarixi bildirişləri, 4 müstəqil mənbəni, 10 dəqiqə davamlı yüksək sıxlığı, yaradılan xəbərdarlığı və **Əlavə avtobus ehtiyatı ayrılmalıdır** tövsiyəsini göstərir.

**1:50–2:00** — Operator panelində planlaşdırılan tədbiri tarixçəyə yazın. “Bu yalnız plandır; sistem avtobus göndərmir.”
